# Webhook & Notification Dashboard
A dashboard for receiving, logging and monitoring webhook events and the notifications they trigger.
## Features
- Webhook endpoint receiving and logging incoming events (JSON payloads)
- Event history with status tracking (received / processed / failed)
- Notification log linked to each event
- Search and filter over past events
## Tech stack
PHP · REST APIs · JSON · MySQL · JavaScript
